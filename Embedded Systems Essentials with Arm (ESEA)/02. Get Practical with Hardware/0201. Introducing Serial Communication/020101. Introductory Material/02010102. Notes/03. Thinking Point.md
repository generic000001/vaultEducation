# Thinking Point: Morse Code and the Origins of Serial Communication

## Context

The principles behind modern serial communication can be illustrated using one of the earliest standardised electrical communication systems: **Morse code**.

---

## Morse Code as a Communication Protocol

International Morse Code was defined in **1865**, building on the work of American inventor **Samuel Morse** and subsequent refinements made in Germany and elsewhere.

In modern terminology, Morse code can be thought of as a **communication protocol**:

> A protocol is an agreed set of rules governing how communication takes place.

The importance of the agreement is that both the sender and receiver interpret the transmitted signals according to the same rules.

To somebody unfamiliar with Morse code, the signals may appear meaningless. A trained operator, however, can identify the boundaries between symbols, letters and words and reconstruct the original message.

---

## From Dots and Dashes to Bits

Morse code is based primarily on two signal states:

- **Dot** (`.`)
- **Dash** (`-`)

Silence and timing are also essential because they separate the individual parts of the message.

Modern digital communication similarly represents information using two logic states:

- **0**
- **1**

These binary values are called **bits**.

The comparison is not that dots and dashes literally *are* binary bits. Rather, both systems encode information using a small set of defined signal states whose meaning is understood by the sender and receiver.

---

## Why Morse Code Is Serial Communication

Morse code provides a useful analogy for **serial communication** because information is transmitted sequentially.

```text
Signal
  ↓
Dot / Dash
  ↓
Letter
  ↓
Word
  ↓
Message
```

Each unit is sent **one after another over a single communication channel**, which may be a physical wire or a wireless radio link.

This is the central idea behind serial communication:

> Information is transferred sequentially over a communication channel and reconstructed by the receiver according to an agreed protocol.

---

## SOS Distress Signal

The internationally recognised Morse distress signal is:

```text
... --- ...
```

It consists of:

```text
3 short signals
3 long signals
3 short signals
```

Morse code became particularly important for maritime communication, where wireless operators could transmit distress messages over radio.

The course uses the example of a cargo ship in distress to illustrate the process:

```text
Ship in distress
      │
      ▼
Radio operator encodes message
      │
      ▼
Morse signals transmitted sequentially
      │
      ▼
Remote radio operator receives signals
      │
      ▼
Protocol used to decode signals
      │
      ▼
Original message reconstructed
      │
      ▼
Rescue response coordinated
```

Morse code remained in international maritime use for more than a century before being phased out from this role in **1999**.

---

## Connection to Embedded Systems

The Morse code example introduces several ideas that also appear in embedded communication systems:

| Morse communication | Embedded serial communication |
|---|---|
| Dot and dash | Logic 0 and logic 1 |
| Telegraph/radio channel | Electrical communication channel |
| Symbols transmitted sequentially | Bits transmitted sequentially |
| Timing and pauses separate information | Timing/framing identifies data boundaries |
| Morse protocol defines interpretation | Serial protocol defines interpretation |
| Trained operator decodes message | Hardware/software decodes received data |

The key principle is **shared interpretation**.

A transmission is useful only when the sender and receiver agree on how the sequence of signals should be interpreted.

## Historical Thinking Point: The First SOS at Sea

The course asks learners to investigate the first recorded ship rescue involving the Morse **SOS** distress signal, providing **1909** as a hint.

### RMS Slavonia

The event generally associated with the first shipboard use of the SOS distress signal involved the **RMS Slavonia**, a Cunard Line passenger ship.

On **10 June 1909**, Slavonia ran aground in the **Azores**. An SOS distress message was transmitted and everyone aboard was rescued, although the vessel itself was subsequently declared a total loss.

This is distinct from another important event later that year involving the **SS Arapahoe**, which is recognised as the first American ship-to-shore use of SOS.

On **11 August 1909**, Arapahoe became disabled near **Cape Hatteras, North Carolina**, after its propeller shaft broke. Wireless operator **Theodore Haubner** transmitted an SOS distress call.

### Why the distinction matters

```text
10 June 1909
RMS Slavonia
      ↓
Early/first recorded shipboard SOS
      ↓
Grounded in the Azores

11 August 1909
SS Arapahoe
      ↓
First American ship-to-shore SOS
      ↓
Disabled near Cape Hatteras
```

The historical terminology varies depending on whether a source is describing the **first use of SOS by a ship** or the **first American ship-to-shore SOS**, so the two incidents should not be conflated.

---

## Key Takeaway

> Morse code provides an early and intuitive example of a serial communication protocol: information is encoded into defined signals, transmitted sequentially over a communication channel, and reconstructed by a receiver that understands the same rules. Modern embedded serial protocols apply the same fundamental idea using digital logic, bits, precise timing and electronic hardware.

# Module 1: Learning Objectives

## Module Goal

By the end of **Module 1**, you should be able to:

> Explain the principles of simple serial data communication and implement simple synchronous and asynchronous serial links using CMSIS.

---

## Learning Objectives

To achieve the module goal, you should be able to:

### 1. Understand Serial Data Communication

Explain the essential principles of **serial data communication**, including the role played by **shift registers** when transmitting and receiving data.

Key concepts:

- Serial data communication
- Sequential data transfer
- Shift registers
- Data transmission
- Data reception

### 2. Understand Synchronous Serial Communication

Describe the essential features of a simple **synchronous serial link**, using **SPI (Serial Peripheral Interface)** as the main example.

Key concepts:

- Synchronous communication
- SPI
- Serial data
- Clocked communication

### 3. Understand Asynchronous Serial Communication

Describe the essential features of a simple **asynchronous serial link** and the role of the **UART (Universal Asynchronous Receiver/Transmitter)** serial port.

Key concepts:

- Asynchronous communication
- UART
- Serial transmission and reception

### 4. Implement Serial Links Using CMSIS

Implement simple synchronous and asynchronous serial links in a **physical hardware environment** using **CMSIS**.

This moves the module from understanding the protocols conceptually to applying them on embedded hardware.

### 5. Compare Synchronous and Asynchronous Communication

Evaluate the relative advantages of simple synchronous and asynchronous serial links and identify their limitations when applied to more complex systems.

The important question is therefore not simply *how does each protocol work?*, but also:

> When is each approach appropriate, and where does it begin to become inadequate?

---

## Knowledge vs Practical Skills

| Knowledge | Practical application |
|---|---|
| Principles of serial communication | Implement a serial link |
| Role of shift registers | Transmit and receive data |
| Features of SPI | Implement synchronous communication |
| Features of UART | Implement asynchronous communication |
| Advantages and disadvantages | Select an appropriate approach for a system |
| Limitations of simple serial links | Recognise issues in more complex systems |

---

## Key Takeaway

> Module 1 progresses from understanding how serial data is physically transmitted and received, through SPI and UART, to implementing both approaches using CMSIS and evaluating when each communication method is appropriate.

### Question

SPI is an important and well-established means of serial data communication. Identify the correct statements.

**Select all correct answers.**

1. When idling in an SPI data link, the clock signal continues, but the data is held at logic 0.

2. SPI stands for Serial Protocol Interface; it was agreed internationally in 1979.

3. An SPI network can be set up with one Controller and multiple Targets.

4. Standard terminology for SPI connections includes COTI, CITO, CS, and SCK.

5. The maximum clock speed for an SPI data link is 2 MHz.

### Answer

The two correct statements are:

- **An SPI network can be set up with one Controller and multiple Targets.**

- **Standard terminology for SPI connections includes COTI, CITO, CS, and SCK.**

### Explanation

1. The SPI clock does **not need to continue while the interface is idle**. Its idle level is determined by the configured clock polarity.

2. SPI stands for **Serial Peripheral Interface**, not Serial Protocol Interface.

3. An SPI system can contain **one Controller and multiple Target devices**.

4. The course uses **COTI**, **CITO**, **CS**, and **SCK** for the principal SPI signals.

5. SPI does not have a universal maximum clock frequency of 2 MHz. The usable frequency depends on the hardware and system.

# Course Material Overview and Navigation

## Course Overview

**Embedded Systems Essentials with Arm: Get Practical with Hardware** is intended for learners with:

- Prior knowledge of undergraduate-level engineering principles
- A basic understanding of programming in C/C++

The course builds practical knowledge of serial communication, real-time operating systems, microcontroller peripherals, and CMSIS APIs using the **ST Nucleo F401RE** development board.

---

## What the Course Covers

### 1. Serial Communication

The course covers key **serial communication technologies** and how they are supported through the **CMSIS API**.

### 2. Real-Time Operating Systems (RTOS)

You will learn the basic features of a **Real-Time Operating System (RTOS)** and how these features are supported by **CMSIS**.

### 3. Microcontroller Peripherals

The course examines microcontroller peripherals and how they can be controlled through the **CMSIS API**, including:

- Digital I/O
- Analogue I/O
- Interrupts
- Pulse-width modulation (PWM)
- Timers

### 4. CMSIS-RTOS APIs and Practical Application

You will use **CMSIS-RTOS APIs** to design and create a **music player** using the **ST Nucleo F401RE** development board.

## Course Structure

- **Duration:** 4 weeks
- **Expected study time:** approximately 3 hours per week
- **Modules:** 4
- Most course content is delivered through **edX**

### Ways to Navigate the Course

There are two suggested approaches:

1. **Sequential approach**: work through each module step-by-step.
2. **Guided approach**: use the **Initial Reflection Surveys** and **Initial Assessments** at the beginning of each module to help guide your learning journey.

## Assessment and Certification

Each of the four modules ends with a **Final Assessment**.

To receive a course certificate:

- Complete all **4 Final Assessments**
- Achieve an **average grade of at least 60%** across them
- Each Final Assessment can be attempted **3 times**
- Each Final Assessment is **equally weighted** when calculating the final course average

The following activities **do not contribute to the final course grade**:

- Initial Assessments
- Knowledge Exercises

## Inclusive Language Commitment

Arm aims to use language that is **inclusive, meaningful, and respectful** and is working with partners, standards bodies, and the wider ecosystem to replace non-inclusive terminology.

The course has been updated to use newer terminology where appropriate.

### I2C and SPI Terminology

In the context of **I2C** and **SPI**, the course uses:

| Current terminology | Previous terminology |
|---|---|
| Controller | Master |
| Target | Slave |
| CITO | MISO |
| COTI | MOSI |

The course therefore uses **Controller** and **Target**, with the related signal terminology **CITO** and **COTI**.
